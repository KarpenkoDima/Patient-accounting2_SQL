> [!IMPORTANT]
> **Статус: архив / разработка прекращена.**
>
> Это снимок SQL-кода старого проекта учёта пациентов диспансера.
> Репозиторий сохранён для истории, разбора legacy-кода и восстановления
> структуры предметной области. Он не поддерживается и не предназначен
> для production-использования или хранения реальных медицинских данных.

## Важные ограничения

- это набор выгрузок объектов из SQL Server Management Studio, а не готовый Database Project;
- отсутствует гарантированный сценарий развёртывания БД с нуля;
- часть зависимостей, ролей, данных справочников и служебных объектов отсутствует;
- SQL-код содержит известные проблемы безопасности и транзакционности;
- EF Core-документы являются историческими непроверенными заметками;
- сборка, запуск и совместимость с текущими версиями SQL Server и EF Core не подтверждены.

Подробности перечислены в [`docs/review/KNOWN_ISSUES.md`](docs/review/KNOWN_ISSUES.md).

## Как использовать

Репозиторий допустимо использовать только как:

- архив старого проекта;
- источник для изучения существующей схемы;
- материал для code review и разбора legacy SQL;
- справочник при переносе предметной области в новый проект.

Не следует применять скрипты непосредственно к рабочей базе без ручной проверки,
резервной копии и тестового развёртывания.

## Что делать при возобновлении проекта

Не продолжать разработку непосредственно в этом архиве. Создать новый репозиторий
и переносить в него только проверенные части схемы и бизнес-правил. Для схемы выбрать
один механизм управления: SQL Database Project либо EF Core migrations, но не оба
одновременно для одной и той же базы.
