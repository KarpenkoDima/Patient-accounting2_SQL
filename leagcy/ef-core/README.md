# Материалы по EF Core

Материалы построены вокруг реальной legacy-базы Patient-accounting2.

## EF_Core_Guide.md

Базовое руководство:

- сущности и связи;
- Fluent API;
- database-first;
- представления;
- хранимые процедуры;
- запросы;
- soft delete.

Подходит для изучения интеграции EF Core с существующей SQL Server базой.

## EF_Core_Advanced_Guide.md

Расширенный материал:

- транзакции;
- производительность;
- domain events;
- outbox;
- шифрование;
- интеграционные тесты.

Некоторые разделы показывают направление решения, но требуют
доработки перед применением в production.

## Статус

Материалы заморожены и сохраняются как учебно-исторические.
Они не обновляются под текущую версию EF Core.
